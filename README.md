# E-Commerce & Inventory Management System

A production-grade e-commerce and inventory management system with multi-vendor support, built using modern web technologies.

## Tech Stack
- **Frontend**: React, TypeScript, Redux Toolkit, TailwindCSS
- **Backend**: Node.js, Express.js, TypeScript
- **Database**: MongoDB (Primary), Redis (Cache/Session)
- **Infrastructure**: Docker, Docker Compose

## Quick Start
1. Clone the repository
2. Copy `.env.example` to `.env` and fill in the necessary environment variables.
3. Run `docker-compose up --build` to start all services (frontend, backend, database, cache).

For development, you can also run the frontend and backend separately using `npm run dev` in their respective directories.
